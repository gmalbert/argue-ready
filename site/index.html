Privacy, made explicit

Know what happens
before you speak.

ArgueReady is built for counsel-controlled rehearsal. The app checks Apple’s speech capability for this device and language before recognition starts.

On-device onlyiPhone and iPad on iOS/iPadOS 17 or later are supported by the app. Apple’s runtime check determines whether the selected device and language can recognize speech locally.
If local recognition is unavailableArgueReady stops and tells you. It does not silently switch to network processing. Choose Hybrid only when you explicitly allow Apple’s network-assisted recognition.
What is savedRaw audio is not saved. Transcript saving is optional and local. Matter data, coverage, checkpoints, and reports stay on the device; the Watch receives checklist state only.

For counsel and teams

Designed for
high-stakes clarity.

Does argue ready write arguments for counsel?+

No. It tracks prepared requirements and retrieves counsel’s own notes, authorities, and record cites. The lawyer remains in control of the argument and the strategy.

What happens when the bench interrupts?+

The system can surface the prepared response or context card, then preserve the place in the main argument so counsel can return to the next unfinished obligation.

Can teams use their own authorities and record cites?+

That is the intended workflow: compact, glanceable cards for the authorities, record references, and “do not concede” notes the team prepared before argument.

Does it record the hearing?+

No. ArgueReady can use the microphone during a counsel-controlled rehearsal for speech recognition, but it does not save raw audio or create a courtroom recording by default.

Which devices and languages support on-device recognition?+

ArgueReady supports iPhone and iPad on iOS/iPadOS 17 or later. Apple reports on-device support at runtime for the selected device and language, so there is no dependable model-only cutoff. ArgueReady checks before each rehearsal and shows the result.

What happens if on-device recognition is unavailable?+

On-device only stops and explains why. It does not silently switch to network processing. Hybrid is a separate setting that may use Apple’s network-assisted recognition only when you explicitly choose it.

Is there a transcript?+

The live transcript is held in memory by default. If Save transcript locally is enabled, the completed transcript is saved with the rehearsal report on the iPhone or iPad; raw audio is not saved.

What are my options?+

Use ArgueReady with prepared material only, use On-device only for local speech recognition, or choose Hybrid when you explicitly allow Apple’s network-assisted recognition. You decide what is captured, what is stored, and who can access it.
